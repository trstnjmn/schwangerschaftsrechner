# 👶 Schwangerschaftsrechner

Ein moderner, minimalistischer Schwangerschaftsrechner gebaut mit **Next.js 15**, **React** und **Tailwind CSS v4**.

Berechne die aktuelle Schwangerschaftswoche (SSW) sowie Tag, den voraussichtlichen Entbindungstermin und verfolge die wichtigsten Entwicklungsphasen über eine übersichtliche Zeitleiste.

---

## 🚀 Features

* **Zwei Berechnungsmodi:** Wahlweise über den ersten Tag der letzten Periode oder den errechneten Entbindungstermin.
* **Präzise Anzeige:** Genaue Berechnung von SSW + Tagen sowie Anzeige der aktuellen Kalenderwoche.
* **Interaktive Zeitleiste:** Automatische Hervorhebung des aktuellen Entwicklungsstadiums (Einnistung, Embryonalphase, Fötalphase, etc.).
* **Responsive & Clean UI:** Optimiert für Smartphones und Desktop im sanften Pastell-Design.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org) (App Router)
* **UI Library:** [React](https://react.dev)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
* **Fonts:** [Geist Sans & Geist Mono](https://vercel.com/font)
